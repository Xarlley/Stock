# ETF 全景清单（数据拉取参考）

> **用途**：作为每次盘前/盘中数据拉取的标的清单。每个板块和国家/区域至少选 2 只 ETF,便于做流动性 + 跟踪误差对比,避免单一基金管理人风险。
>
> **维护原则**：
> - "**已验证**"列在 2026-05-26 至少成功拉取过一次实时盘口和日 K 历史
> - "**候选（待验证）**"是常见代码但本项目尚未实际跑过,首次使用时若失败请删除或换码
> - 代码变更频繁的子类（新发 ETF、合并、转型）应定期校验

## 七、注意事项

1. **接口稳定性**：`fund_etf_hist_em` 在本项目所在网络环境下高频失败,历史日 K 默认走 `fund_etf_hist_sina` 兜底。详见 [data_sources.md](data_sources.md) 与 memory `reference_akshare_quirks`。
2. **批量 Sina 实时**：超过约 20 个代码合并到一个 `hq.sinajs.cn/list=` URL 时会 ConnectTimeout,大批量场景改走 `fund_etf_spot_em` 一次性拉全市场后本地筛选。
3. **代码核验**：不确定的代码先用 `python main.py <code>` 单独验证,确认名称和实际跟踪指数与预期一致后再加入清单。
4. **重复跟踪**：同板块多只 ETF 间相关性常 >0.95,选 2 只用于流动性切换与申赎成本对比,不应同时重仓。
5. **跨境 ETF 溢价警戒**：513100 / 159941 / 159509 / 513500 / 159866 / 513030 / 513080 / 513310 均为跨境品种,买入前必查 IOPV 溢价。详见 [data_sources.md §6.1](data_sources.md)。
